### Task 4: Build and install exact local 1.4.2 wheels

**Files:**
- Build artifacts only; no tracked source modifications.

- [ ] **Step 1: Build all three wheels from committed main**

Run from `/home/john/loomweave`:

```bash
INSTALL_DIST=$(mktemp -d)
uv build --wheel --out-dir "$INSTALL_DIST" crates/loomweave-cli
uv build --wheel --out-dir "$INSTALL_DIST" plugins/python
uv build --wheel --out-dir "$INSTALL_DIST" packaging/rust-plugin-dist
CLI_WHEEL=$(find "$INSTALL_DIST" -maxdepth 1 -type f -name 'loomweave-*.whl' ! -name 'loomweave_plugin_*' -print -quit)
PYTHON_WHEEL=$(find "$INSTALL_DIST" -maxdepth 1 -type f -name 'loomweave_plugin_python-*.whl' -print -quit)
RUST_WHEEL=$(find "$INSTALL_DIST" -maxdepth 1 -type f -name 'loomweave_plugin_rust-*.whl' -print -quit)
test -f "$CLI_WHEEL" && test -f "$PYTHON_WHEEL" && test -f "$RUST_WHEEL"
```

Expected: exactly one usable 1.4.2 wheel exists for each distribution.

- [ ] **Step 2: Force-reinstall the local wheel set**

Run:

```bash
uv tool install --force --reinstall --no-cache "$PYTHON_WHEEL"
uv tool install --force --reinstall --no-cache "$RUST_WHEEL"
uv tool install --force --reinstall --no-cache "$CLI_WHEEL" \
  --with "$PYTHON_WHEEL" --with "$RUST_WHEEL"
hash -r
```

Expected: uv replaces all three 1.4.1 tools with the local 1.4.2 wheels.

Run:
