# Loomweave Docs

## Read paths

## Structure

- [1.0/](./1.0/README.md) — current versioned spec set.
- [adr/](./adr/README.md) — authored architecture decision records and the remaining backlog.
- [proposals/](./proposals/) — cross-member proposals not yet ratified as ADRs; currently [C-9-shared-weft-toml-schema.md](./proposals/C-9-shared-weft-toml-schema.md) (shared `weft.toml` key layout).

## Canonical vs supporting

- Canonical design docs for the current product version live under `1.0/`.
- Reviews and planning history are archived under [../implementation/](../implementation/) and [1.0/reviews/](./1.0/reviews/) — non-normative supporting context.
